# Amoeba Documentation

Welcome to the internal documentation for **Amoeba**, a source-code search and indexing engine.

## Documentation Structure

The documentation is organized into four main sections:

* [`architecture/`](file:///d:/amoeba/docs/architecture/overview.md): High-level system design, conceptual layered architecture, components, and module boundaries.
* [`decisions/`](file:///d:/amoeba/docs/decisions/ADR-001-cpp.md): Architecture Decision Records (ADRs) capturing significant technical and architectural choices, rationale, trade-offs, and consequences.
* [`phases/`](file:///d:/amoeba/docs/phases/phase-00-foundation.md): Detailed roadmaps, scope definitions, non-goals, and checkpoint criteria for each project phase.
* [`research/`](file:///d:/amoeba/docs/research/README.md): Investigations, literature reviews, benchmarking experiments, algorithm explorations, and performance analyses.

## Guiding Engineering Philosophy

> **Build the core, reuse mature infrastructure, measure bottlenecks, and replace components only when there is a good engineering reason.**

All contributors and architects should reference these documents before proposing architectural modifications or premature implementations.
